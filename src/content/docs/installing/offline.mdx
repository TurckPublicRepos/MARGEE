This guide walks you through installing the Margee extension manually using a .VSIX file. Use this method if you need to install Margee without internet access or prefer to install from a local file.

## Prerequisites

Before you begin, ensure you have:
- [Visual Studio Code](https://code.visualstudio.com/) installed and running
- The [Margee .VSIX file](https://turck.com/)
- A supported operating system (Windows, macOS, or Linux)

## Installation Steps

### 1. Open Visual Studio Code

Launch Visual Studio Code on your computer. You can open it with or without a folder - the extension installation process is the same either way.

### 2. Access the Extensions View

Open the Extensions view by using one of these methods:
- Click the **Extensions icon** (four squares) on the left sidebar
- Use the keyboard shortcut `Ctrl+Shift+X` (Windows/Linux) or `Cmd+Shift+X` (macOS)
- Go to the menu: **View** → **Extensions**

The Extensions view will open on the left sidebar.

### 3. Install from VSIX File

In the Extensions view, look for the menu icon (three dots) at the top and click it:
- Click the **three-dot menu** button in the top right of the Extensions view
- Select **"Install from VSIX..."** from the dropdown menu

A file browser dialog will open.

### 4. Browse and Select the .VSIX File

In the file browser:
- Navigate to the location where you saved the Margee `.vsix` file
- Select the file
- Click **Open** (or **Select Folder**, depending on your OS)

VS Code will begin installing the extension from the selected file.

### 5. Confirm Installation and Reload

After the file is selected:
- VS Code will display installation progress in the status bar
- Once complete, a **Reload** button may appear, or you may need to restart VS Code manually

Click the Reload button if it appears, or close and reopen VS Code. The Margee extension will now be active and ready to use.
