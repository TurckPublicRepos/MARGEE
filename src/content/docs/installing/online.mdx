---
title: Online installation (Marketplace)
---

This guide walks you through installing the Margee extension directly from the Visual Studio Code Marketplace. This is the quickest and easiest way to get started, as it requires only an internet connection and doesn't involve manual file downloads.

## Prerequisites

Before you begin, ensure you have:
- [Visual Studio Code](https://code.visualstudio.com/) installed and running
- An internet connection
- A supported operating system (Windows, macOS, or Linux)

## Installation Steps

### 1. Open Visual Studio Code

Launch Visual Studio Code on your computer. You can open it with or without a folder - the extension installation process is the same either way.

### 2. Access the Extensions View

Open the Extensions view by using one of these methods:
- Click the **Extensions icon** (four squares) on the left sidebar
- Use the keyboard shortcut `Ctrl+Shift+X` (Windows/Linux) or `Cmd+Shift+X` (macOS)
- Go to the menu: **View** → **Extensions**

The Extensions view will open on the left sidebar, showing the Extensions Marketplace search interface.

### 3. Search for the Margee Extension

In the search box at the top of the Extensions view:
- Type `Margee`
- Wait a moment for the search results to load

You should see the official Margee extension listed in the results. The extension should show:
- The Margee name and icon
- A brief description of the extension
- The publisher/author information
- A blue **Install** button

### 4. Install the Extension

Click the blue **Install** button next to the Margee extension. This will:
- Download the extension package from the marketplace
- Unpack and install it into your VS Code configuration
- Display installation progress in the status bar

The installation typically completes in a few seconds, depending on your internet speed.

### 5. Confirm Installation and Reload

After installation completes:
- A **Reload** button may appear automatically, or
- You may need to restart VS Code manually to fully activate the extension

Simply click the Reload button if it appears, or close and reopen VS Code. The Margee extension will now be active and ready to use.
