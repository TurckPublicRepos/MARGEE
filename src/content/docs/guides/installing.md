## Installing Margee in Visual Studio Code

You can install the Margee extension for Visual Studio Code using two methods: online via the Marketplace, or offline using a `.vsix` file.

### Method 1: Online (Marketplace)

1. **Install Visual Studio Code**  
   If you haven't already, download and install [Visual Studio Code](https://code.visualstudio.com/) for your operating system.

2. **Open Visual Studio Code**  
   Launch VS Code from your desktop or start menu.

3. **Open Extensions View**  
   Click the Extensions icon on the left sidebar (or press `Ctrl+Shift+X`).

4. **Search for Margee**  
   In the search box, type `Margee`.

5. **Install the Extension**  
   Find the Margee extension in the results and click `Install`.

6. **Reload/Restart VS Code**  
   After installation, reload VS Code if prompted.

### Method 2: Offline (.vsix file)


1. **Install Visual Studio Code**  
   If you haven't already, download and install [Visual Studio Code](https://code.visualstudio.com/) for your operating system.

2. **Obtain the `.vsix` File**  
   Download the Margee extension `.vsix` file from our Turck website.

3. **Open Visual Studio Code**

4. **Open Command Palette**  
   Press `Ctrl+Shift+P` (or `F1`) to open the Command Palette.

5. **Run: "Extensions: Install from VSIX..."**  
   Type `Extensions: Install from VSIX...` and select it.

6. **Select the `.vsix` File**  
   Browse to the location of your downloaded `.vsix` file and select it.

7. **Reload/Restart VS Code**  
   After installation, reload VS Code if prompted.

---

Once installed, you can start using Margee features in your projects.
