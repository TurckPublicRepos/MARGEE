## Creating a New Margee Project

To quickly start with Margee, you can use the built-in command to create a new sample project:

1. **Open Visual Studio Code.**
2. **Open the Command Palette:**  
   Press `Ctrl+Shift+P` (or `F1`).
3. **Run the Command:**  
   Type `MARGEE: Create a new Margee project` and select it.
4. **Enter a Project Name:**  
   You will be prompted to enter a name for your new project.
5. **Choose a Folder:**  
   Select the folder where you want your project to be created.

Margee will generate a sample project with the necessary files and structure. You can then start editing and exploring your new project.

## Sample Project Overview

The generated sample project typically includes:

- **Project Settings (`.tps`):**  
  Configuration file for device, I/O, and project parameters.
- **Structured Text (`.tst`):**  
  Example logic for your Turck FLC device, including sample tasks and variables.
- **Web View (`.twv`):**  
  A basic web interface for your device, demonstrating markup, JavaScript, and styling.
- **Assets and Documentation:**  
  Additional folders for images, stylesheets, or help files.

This structure provides a working starting point, allowing you to experiment with device logic, web visualization, and configuration. You can modify or extend any part of the sample to fit your application.
